# ML-NBA: Previsor de Vencedor da NBA

Projeto de Machine Learning para prever vencedores de partidas da NBA e simular o campeão da temporada através de modelos estatísticos e simulações Monte Carlo.

## Estrutura do Projeto

- `src/`: Scripts de coleta de dados, engenharia de atributos (features), modelagem e simulação.
- `data/`: Armazenamento de dados brutos e processados.
- `notebooks/`: Notebooks Jupyter para análise exploratória e experimentação de modelos.
- `requirements.txt`: Dependências do projeto.

## Como Configurar e Executar

1. **Ativar o Ambiente Virtual:**
   ```powershell
   .venv\Scripts\Activate.ps1
   ```
   *(Em caso de restrição de scripts no PowerShell, execute: `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`)*

2. **Instalar Dependências:**
   ```powershell
   pip install -r requirements.txt
   ```
